One satirical sentence, at most 320 characters: lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF. Congress can write 400 pages of rules for machines that think — and still gets back a sideways photograph of its own monitor.

## Run it

```sh
node main.ts
```

Writes the sentence to `/output/entry.txt` (or `$ENTRY_OUTPUT`), no trailing newline.
